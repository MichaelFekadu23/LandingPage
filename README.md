# LandingPage Repository Documentation

## Overview

The **LandingPage** repository is a responsive landing page project for the Moto rideshare concept. It emphasizes modern web aesthetics using gradients, depth, and clarity. The source code leverages a contemporary frontend stack centered around React, Vite, and Tailwind CSS.

---

## Tech Stack

| Layer          | Technology                 | Purpose/Description                                                      |
|----------------|---------------------------|--------------------------------------------------------------------------|
| UI Components  | React                     | Component-based JS library for building UIs                              |
| Transpilation/Build | Vite               | Fast modern build tool; manages dev server, hot reload, and building     |
| Styling        | Tailwind CSS              | Utility-first CSS framework for rapid styling                            |
| CSS Processing | PostCSS + Autoprefixer    | Enables advanced CSS transformations and automatic vendor prefixing       |

---

## Project Structure

- `src/`             : Source code (React components, assets)
- `public/`          : Static assets served directly
- `dist/`            : Build output (generated by Vite)
- `index.html`       : Main HTML entry point
- `package.json`     : Dependency and script definitions
- `vite.config.js`   : Vite configuration
- `tailwind.config.cjs` : Tailwind customizations
- `postcss.config.cjs`  : PostCSS config
- `README.md`        : Documentation

---

## Key Dependencies & Their Functions

### Dependencies

- **react**: Library for building encapsulated interactive UI components.
- **react-dom**: Provides DOM-specific methods for React.

### DevDependencies

- **@types/react**/**@types/react-dom**: TypeScript typings for React (enables type checking in editors and builds).
- **@vitejs/plugin-react**: Integrates React with Vite; enables fast refresh and JSX support.
- **autoprefixer**: PostCSS plugin that adds/removes vendor prefixes from CSS automatically.
- **postcss**: CSS processing framework; used to apply Tailwind and other CSS transformations.
- **tailwindcss**: Provides utility-based CSS framework for customizable, scalable designs.
- **vite**: Modern frontend build tool for lightning-fast dev/build.

---

## Configuration Files

### Vite (`vite.config.js`)

- Plugins: Adds React support with `@vitejs/plugin-react`.
- Entry point for configuring dev/build server and plugin integration.

```js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
});
```

---

### Tailwind CSS (`tailwind.config.cjs`)

- **Content**: Scans `index.html` and all JS/TS/JSX/TSX files in `src` for class usage.
- **Dark Mode**: Enabled via class or html attribute.
- **Theme Extension**: Custom colors (`charcoal`, `emerald`), fonts (e.g., `Poppins`, `Inter`), shadows, and background gradients.
- **Plugins**: None by default; can extend for forms, typography, etc.

---

### PostCSS (`postcss.config.cjs`)

- Loads Tailwind CSS and Autoprefixer.
- Processes all CSS, applying Tailwind utilities and adding vendor prefixes for compatibility.

## Usage

**Install dependencies:**
```sh
npm install
```

**Start development:**
```sh
npm run dev
```

**Build for production:**
```sh
npm run build
```

**Preview build locally:**
```sh
npm run preview
```
